# Retail Stock Transfer MIS Dashboard

## 📊 Project Overview

The **Retail Stock Transfer MIS Dashboard** is an analytics-driven decision support system designed to optimize **inventory distribution across retail stores**.

Retail chains frequently face challenges such as:

* Overstock in low-performing stores
* Stockouts in high-demand locations
* Inefficient inter-store transfers
* Poor visibility into sell-through performance

This project provides a **data-driven framework** to analyze store-level inventory performance and recommend actionable stock transfer insights.

---

## 🎯 Business Problem

In multi-store retail environments, inventory imbalance directly impacts:

* Lost sales opportunities
* Increased markdown costs
* Excess working capital blockage
* Reduced inventory turnover

Manual decision-making based on intuition often leads to inefficient stock allocation.

This dashboard enables **objective, analytics-based transfer planning**.

---

## 🚀 Key Features

✅ Store-wise inventory performance analysis
✅ Sell-through % (ST%) monitoring
✅ Size-level stock visibility
✅ Identification of surplus vs deficit stores
✅ Transfer planning support
✅ Interactive MIS dashboard for business users

---

## 🧠 Analytics Approach

The dashboard applies retail analytics concepts such as:

* Sell Through Percentage (ST%)
* Inventory Aging Analysis
* Demand vs Availability comparison
* Store performance benchmarking
* Data-driven redistribution logic

These insights help merchandisers and planners take faster operational decisions.

## ▶️ How to Run the Project

### 1. Clone Repository

```bash
git clone https://github.com/bimleshkanth/retail-stock-transfer-mis-dashboard.git
cd retail-stock-transfer-mis-dashboard
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

### 3. Activate Environment

**Windows**

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run Dashboard

```bash
streamlit run retail_mis_app.py
```
